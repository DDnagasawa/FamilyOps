# RSS News Briefing

Use this skill to collect recent items from configured RSS/news feeds and turn them into a short briefing.

Inputs:

- `feedUrls`: optional array of RSS/Atom URLs. If omitted, `RSS_FEED_URLS` is used.
- `limit`: optional number of items to include.
- `sendLark`: optional boolean for Lark delivery.

The skill is read-only and should not perform publishing or local file changes.
