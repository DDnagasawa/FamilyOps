# Family Todo List

Use this skill when the user asks to see or send the family todo list.

Natural user phrases:

- "show my todo list"
- "send family todo list"
- "显示今天的待办"
- "把待办卡片发到 Lark"

The skill reads open family tasks and shopping items, builds a Lark interactive card, and sends it through the configured Lark app API. Each item has a Done button. The callback server handles the button and marks the item as done in the local family plan.
